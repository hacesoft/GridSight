# Changelog

## 1.0.0 — 2026-10-20

First public GridSight release for Nextcloud 35.

### Features
- Live photovoltaic production, home consumption and grid-flow overview.
- Measurement history, interactive charts and energy totals.
- Electricity price and billing analysis.

### Compatibility
- Nextcloud 35, PHP 8.3+.
- Requires HC Shared App Core 0.18.8 or newer.

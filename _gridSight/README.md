# GridSight

GridSight is a read-only Nextcloud 35 application for the LINEA API. It displays live solar production, house consumption, grid flow, battery and ESS state, SPOT prices, device readings and measured history. It does not send control commands to the plant.

<img width="2134" height="1153" alt="image" src="https://github.com/user-attachments/assets/6cae686b-1849-446d-9b7d-cb213ddca6f2" />

The technical ID is `hc_gridsight`. GridSight requires enabled Shared App Core `>= 0.18.0-dev.2` and a reachable, read-only LINEA API with schema `1`. Install from the **complete source ZIP** containing `install.sh`, `scripts/` and `src/`.

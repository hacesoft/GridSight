# GridSight – dokumentace

GridSight zobrazuje energetické a technické údaje poskytované LINEA API uvnitř Nextcloudu. Živý přehled je jen pro čtení; vlastní databáze slouží k historii, událostem a dennímu vyhodnocení dodávky. Rozhraní a společné služby poskytuje Shared App Core.

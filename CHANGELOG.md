# Changelog

## 1.0.1 — 2026-11-21

- Documented internal Hungarian-style variable prefixes and added Czech input/output contracts for functions and callbacks.

- Temporary Node-RED / LINEA API outages show a friendly informational notice without cURL diagnostics and automatically recover when the connection returns.
- Transport outages are distinguished from incompatible API contracts and actual application errors.
- Light and dark UI surfaces, labels, forms and chart texts now follow the current Nextcloud theme.
- Versioned 1.0.1 assets to avoid stale browser caches.
- Expanded multilingual feature descriptions, Czech/English guides and UI translations.
- Documented the 18-step installer; added an optional Hungarian UI translation.


## 1.0.0 — 2026-10-20

First public GridSight release for Nextcloud 35.

### Features
- Live photovoltaic production, home consumption and grid-flow overview.
- Measurement history, interactive charts and energy totals.
- Electricity price and billing analysis.

### Compatibility
- Nextcloud 35, PHP 8.3+.
- Requires HC Shared App Core 0.18.8 or newer.

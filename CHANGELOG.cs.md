## 1.0.1 — 2026-11-21

- Upřesněna maďarská notace interních proměnných a doplněny české komentáře vstupů/výstupů funkcí a callbacků.

- Dočasná nedostupnost Node-RED / LINEA API se hlásí jako informační oznámení bez technických podrobností; automatický pokus o opětovné spojení a odstranění oznámení po obnovení služby.
- Odlišení dočasného transportního výpadku od nekompatibilního API a skutečných chyb.
- Sjednoceny podklady, texty, formuláře a grafy s aktuálním světlým či tmavým motivem Nextcloudu.
- Verzované CSS/JS 1.0.1 kvůli obnovení assetů po upgradu.
- Rozšířen vícejazyčný popis funkcí, aktualizovány české a anglické návody a lokalizace rozhraní.
- Instalační dokumentace odpovídá 18krokovému instalátoru; rozhraní je přeloženo také do maďarštiny.


## 1.0.0 — 2026-10-20

První veřejné vydání GridSight pro Nextcloud 35.

### Funkce
- Živé energetické toky a přehled výroby a spotřeby
- Historie měření a 2D/3D grafy
- Spotové ceny a analýzy vyúčtování elektřiny

### Kompatibilita
- Nextcloud 35 a PHP 8.3+.
- Vyžaduje Hacesoft Shared App Core 0.18.8 nebo novější.
